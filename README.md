# 🧸 Caminho Suave

Aplicativo educativo infantil para **Android**, desenvolvido com foco na aprendizagem por meio de imagens, números e sons.

O projeto apresenta uma interface simples e lúdica, pensada para crianças em fase inicial de aprendizagem. Entre os conteúdos disponíveis estão **animais e seus sons** e **números**, utilizando recursos visuais e sonoros para tornar a experiência mais interativa.

> 📱 **Aplicação:** Android  
> 🎓 **Categoria:** Educação infantil  
> 🛠️ **Tecnologia:** MIT App Inventor / plataforma baseada em App Inventor  
> 📦 **Formato:** APK

---

## 📖 Sobre o projeto

O **Caminho Suave** é uma aplicação educacional criada para auxiliar crianças no contato inicial com conteúdos básicos de aprendizagem.

A proposta é utilizar uma abordagem visual e auditiva, permitindo que a criança explore os conteúdos de forma simples e intuitiva.

### Conteúdos disponíveis

- 🐶 **Animais** — apresentação de diferentes animais acompanhados de seus respectivos sons.
- 🔢 **Números** — exploração dos números com elementos visuais e áudio.
- 🔊 **Áudio educativo** — reprodução de sons associados aos conteúdos apresentados.
- 🏠 **Menu inicial** — acesso às atividades disponíveis no aplicativo.

## 🚀 Como instalar

### Android

1. Baixe o arquivo `caminhoSuave.apk`.
2. Transfira o arquivo para um dispositivo Android ou abra-o diretamente no dispositivo.
3. Execute o APK.
4. Caso necessário, permita a instalação de aplicativos provenientes da fonte utilizada para abrir o arquivo.
5. Conclua a instalação e abra o **Caminho Suave**.

> ⚠️ A disponibilidade da instalação pode variar conforme a versão do Android e as configurações de segurança do dispositivo.

## 🛠️ Desenvolvimento

O APK indica que o aplicativo foi criado utilizando a infraestrutura do **MIT App Inventor**, plataforma de desenvolvimento de aplicativos Android baseada em programação visual por blocos.

O projeto compilado contém referências à estrutura `com.google.appinventor.components.runtime` e arquivos `.yail`, características da plataforma App Inventor.

### Plataforma

- **MIT App Inventor**
- **Android**
- Programação visual baseada em blocos
- Recursos multimídia (imagem e áudio)

## 🎯 Objetivos

O projeto tem como objetivos:

- Estimular o aprendizado infantil por meio de recursos interativos;
- Associar imagens a sons;
- Auxiliar no reconhecimento de animais;
- Auxiliar no reconhecimento dos números;
- Tornar o processo de aprendizagem mais visual e divertido;
- Desenvolver uma experiência simples e acessível para crianças.
